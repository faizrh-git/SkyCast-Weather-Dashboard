# Weather Dashboard with Chatbot

HTML/CSS/JS dashboard using the OpenWeather API, Chart.js and the Gemini API.

## Setup
1. Copy `js/config.example.js` to `js/config.js` and add your API keys.
2. Serve the folder locally (e.g. VS Code "Live Server" or `python -m http.server`).
3. Open `test.html` to check the data layer, then `index.html` once the UI exists.
